# Лиза — ML

Владеешь: модель вероятности дефолта, объяснения SHAP, метрика.
Разминка: Give Me Some Credit (Kaggle), бустинг, ROC-AUC на отложенной выборке.
Зачем SHAP: предпринимателю нужен не скор, а «что тянет вниз» — топ-3 фактора идут в `/score`.
Жюри Альфы уже слышало, что люди не доверяют ответам AI без объяснения — объяснимость наш козырь.
Открыто: датасет МСБ (SBA Loans или синтетика) под мок-кейс — выбираешь ты. Ревью модели — с Сашей.

## Как работать с твоей нейронкой (DeepSeek, чат)
Новый чат начинай с `context/ALL.md` и этого файла. Код модели проси кусками и запускай сама — в чат вставляй ошибку целиком.
Числа (ROC-AUC, важность признаков) — только из своего прогона, не из ответа нейронки.
Ноутбук — в `hw/liza/` через Add file → Upload.

## Как вести этот файл
Сюда — всё, что ты узнал по своей сфере и что пригодится команде или твоему агенту: решения,
ссылки, цифры с источником, тупики («пробовал X — не работает, потому что…»). Пишешь коротко,
новое сверху. Агент читает этот файл перед задачей по твоей сфере.
