# Палитра Альфы для мокапов

Источник: дизайн-токены Альфы `alfa-ui-primitives@3.36.0`, файл `styles/colors_bluetint.json` (npm, alfa-laboratory). Цвет из токена, не на глаз.
Шрифт бренда Styrene A (платный, у type.today); в Фигме без лицензии ставь Manrope, он уже в мокапах.
Логотипы: `logos/` из того же пакета. Логотип Альфы только внутри своей демки на хакатоне Альфы, наружу не публикуем.
