## Как работать с твоей нейронкой (GPT / Claude, чат)
Новый чат по хакатону начинай так: вставь `context/ALL.md` целиком, потом этот файл, потом «я Тоня, делаю <пункт>».
Нейронку проси структурировать и упаковывать (выводы интервью в таблицу, текст слайда), но выводы и идеи — твои.
Интервью: после звонка вставь заметки и попроси разложить по вопросам гайда — дословные цитаты не давай ей переписывать.
Результат — файлом в свою папку или в `context/interviews/` через Add file → Upload.

## Как вести этот файл
Сюда — всё, что ты узнал по своей сфере и что пригодится команде или твоему агенту: решения,
ссылки, цифры с источником, тупики («пробовал X — не работает, потому что…»). Пишешь коротко,
новое сверху. Агент читает этот файл перед задачей по твоей сфере.
