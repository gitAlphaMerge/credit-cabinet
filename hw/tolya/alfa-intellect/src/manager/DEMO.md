# Демо менеджера за минуту

Предусловие: /api/config возвращает role: manager из серверной сессии; очередь и отказы подготовлены через серверный сценарий P2. Зелёные заявки в очередь менеджера не попадают.

1. Открыть /bank, выбрать заявку «Не согласен с вариантами». Показать тезисы клиента, проверки с источником и временем, лимит и серверную полноту N из M.
2. Нажать «Предложить вариант» у суммы в пределах лимита. Показать обновлённую очередь. Вариант сверх лимита заблокирован и подписан причиной.
3. Открыть «Отказы», выбрать отказ с ENFORCEMENT. Показать расшифровку «Исполнительное производство» и журнал переходов с актором «система».

Если роль или новые поля P2 ещё не подключены, интерфейс показывает ограничение доступа либо «нет данных». Данные и кредитные лимиты для презентации UI не придумывает.
