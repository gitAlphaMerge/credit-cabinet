# Редизайн ИИ-чата · 17.10.2026

Область: `hw/tolya/alfa-intellect`, ветка `Толя`. Основание — приложенное текстовое задание по UX/UI чата. Банковские операции, финансовые формулы, провайдеры и схема SQLite не менялись. Новые зависимости не устанавливались.

## Что изменилось

- Общая структура: `Chat` отвечает за переписку и режимы, `ChatHistory` — за историю, `ChatComposer` — за поле ввода и документы. Общие параметры поиска/высоты вынесены в `chat-ui.ts`, визуальные токены и правила — в изолированный `chat.css`.
- История: компактный список без рамок вокруг каждого диалога; создание, поиск без учёта регистра и крайних пробелов, очистка, открытие и переименование любого диалога. Панель сворачивается плавно. На телефоне и в split view открывается поверх чата, с затемнением, Escape, удержанием фокуса и `inert` для перекрытого содержимого.
- Переписка: страница занимает рабочую область, текст ограничен колонкой 824 px. Ответы агента без тяжёлых контейнеров, пользовательские сообщения — нейтральные мягкие bubbles. Сохранены безопасный Markdown, расчёт, формулы, график и полный график платежей; финансовые предупреждения оформлены отдельными спокойными карточками.
- Новый диалог: небольшой фирменный акцент, заголовок «Чем помочь вашему бизнесу?», короткое описание и три компактных вопроса. Нажатие сразу отправляет вопрос; отдельная ссылка подбора финансирования не смешивается с подсказками.
- Composer: единая капсула с круглыми действиями; автоувеличение 24–180 px и внутренний скролл; Enter / Shift+Enter и защита IME; фокус, hover, disabled, индикатор ожидания. Переписка прокручивается независимо, поле остаётся снизу.
- Документы: имя и статус файла над полем, открытие проверки извлечённых данных, скрытие плашки без удаления документа. Используется существующее хранилище и существующее подтверждение; плашка не означает, что все данные документа автоматически подтверждены.
- Шапка: компактное название с переименованием, раздельные действия истории и режима. Отдельная страница ↔ совмещённый режим, закрытие/восстановление чата и существующий разделитель сохранены. При переходе в split история не открывается самопроизвольно поверх кнопок.
- Адаптивность: контейнерные правила для узкой панели, мобильная история, компактные финансовые показатели. Исправлена минимальная ширина grid-колонки, из-за которой мобильный split мог обрезать Composer.
- Движение: быстрые переходы истории, сообщений, смены диалога и высоты поля; `prefers-reduced-motion` отключает эффекты.

## Проверки

`npm run verify` — PASS: Prettier, TypeScript, production build, **46/46 тестов**. Пять новых тестов проверяют высоту Composer, поиск, разметку действий, привязку плашек к диалогам и недоступность закрытой истории. Запуск тестов требовал разрешения на локальные сокеты tsx; после запуска вне сетевых ограничений песочницы ошибок нет.

Браузерный сценарий `scripts/check-chat-redesign.cjs` — PASS в Chromium на отдельном сервере `4174` и временной SQLite. Основная пользовательская база на `4173` не очищалась и для тестовых записей не использовалась.

Подтверждено в браузере:

1. Пустое состояние, три быстрых вопроса, капсульная форма поля.
2. Двойной клик по вопросу создаёт одну пару сообщений; Enter отправляет ровно один раз, Shift+Enter переносит строку.
3. Несколько сообщений, создание и открытие старого диалога, переименование через шапку и историю, поиск и отсутствие результатов.
4. Связанный с подбором чат: настоящий программный расчёт, финансовое предупреждение, раскрытие всех 36 строк графика платежей.
5. Длинный черновик ограничен 180 px; CSV загружается, подтверждается и сохраняется ровно один раз, появляется плашка документа.
6. Полный ↔ совмещённый режим, начальная ширина чата около 40%, изменение разделителя клавиатурой, закрытие/восстановление. Черновик, активный диалог и плашка сохраняются; записи переписки не меняются.
7. Полная страница: 1920×1080, 1440×900, 1366×768, 1100×800, 768×1024, 390×844. Проверены отсутствие горизонтального переполнения страницы, ширина текстовой колонки и видимость Composer.
8. Совмещённый режим: 1440×900, 1100×800, 768×1024, 390×844. Проверены границы Composer и кнопки отправки внутри панели.
9. Мобильная история: блокировка фонового чата, Escape и снятие блокировки. Скрытие плашки не удаляет документ. Reduced motion отключает анимацию.

Необработанных ошибок страницы нет. Итоговая консоль тестового браузера: 0 errors, 0 warnings. Скриншоты просмотрены визуально, включая исходное состояние, новый empty state, длинный расчёт, документы, split и мобильную историю.

## Границы проверки и хранение

- Живой платный LLM-вызов не выполнялся: браузер проверял программный режим с сохранённой маркировкой «Демо». Существующие тесты адаптера проверяют контракт без платных вызовов.
- Проверен Chromium с изменением viewport; Safari, реальные мобильные устройства и экранная клавиатура отдельно не проверялись.
- Плашки документов — метаданные UI в памяти App, не новое постоянное хранилище вложений по диалогам. После обновления страницы документы остаются в профиле, но плашки очищаются. Черновик сообщения — тоже память приложения, без обещания сохранения после reload.
- Для QA создана временная БД в `/private/tmp/alfa-chat-ui.*` и локальные скриншоты. Эти файлы не содержат пользовательских банковских данных и не отправляются в GitHub.
- Просмотр: `http://localhost:4173/chat`; нужен существующий аккаунт. После изменения frontend достаточно актуальной production-сборки и обновления вкладки. При остановленном сервере: `npm run build && npm start` из папки приложения.
