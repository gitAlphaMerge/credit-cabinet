# Реализация «Альфа-Интеллект»

Источник: приложенные CODEX_MASTER_PROMPT.md, полный текст MVP DOCX (включая таблицы), семь PNG. Ссылки на Figma и отдельный автономный промпт не приложены. Прямой запрос пользователя разрешает push только в `Толя` и работу только внутри `hw/tolya/`.

| Этап | Экран / действие | Источник |
|---|---|---|
| A | Публичный лендинг, две ветки анкеты, регистрация/вход, совмещённый кабинет/чат | MVP разделы 1–3, PNG 1–5 |
| B | Профиль, DaData/тестовый ИНН, единое хранилище и подтверждение документов | MVP раздел 4, PNG 6 |
| C | Детeрминированное ядро, OpenAI Responses API, сохранённые диалоги | Master 6–7, PNG 7 |
| D | Подбор, версии, история, досье и локальная демозаявка | Master 8 |
| E | Демо-кредит, график, прогноз/стресс и уведомления | Master 9–10 |
| F | Проверка прав, формул, парсеров, браузерных путей, адаптивности | критерии готовности |

Изоляция данных: пользователь → бизнес → документы/чаты/подборы/кредит/уведомления. База SQLite с миграцией при запуске и атомарными сохранениями. Подготовленная структура допускает перенос в PostgreSQL.
