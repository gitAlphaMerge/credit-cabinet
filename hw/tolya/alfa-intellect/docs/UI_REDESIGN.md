## Запуск и границы

Node **24+**. Из корня: `cd hw/tolya/alfa-intellect`, затем `npm ci`, `npm run fixtures`, `npm run build`, `npm start`. Сайт **http://localhost:4173**, демо **http://localhost:4173/demo**. Для разработки — `npm run dev`; остановка Ctrl+C. SQLite и сохранённые документы не удалять. Для демо пароль не нужен и аккаунт не создаётся; для обычного аккаунта — анкета/регистрация.

Не выполненных пунктов нового UX-задания не осталось по проверенным сценариям. Границы прежнего MVP сохранены: нет ключей OpenAI/DaData, поэтому живые внешние интеграции и платные запросы не проверялись; нет реальных банковских действий/SMS/OCR, произвольные формы документов не гарантируются, Docker не установлен и контейнерный запуск не проверялся. Figma не подключалась без ссылки. Не заявляется production-готовность или банковское одобрение.

Браузерные проверки добавили только синтетические QA-аккаунты, их подтверждённые fixture и одну локальную демозаявку в локальной БД; тесты API используют отдельные временные БД. Существующие записи не очищались. Старый корневой `outputs/` сохранён без изменений.
