## Браузерные проверки (Playwright CLI)

Фактически пройдены, а не только проверены HTTP-коды:

1. Лендинг → демовход → пустой кабинет.
2. Полная регистрация действующего ООО; обучение и отсутствие выдуманного кредита.
3. Незарегистрированный проект: условный пропуск ОПФ/возраста регистрации, регистрация, скрытый ИНН и восстановление сессии после reload.
4. ИНН → preview → подтверждение.
5. Все **шесть документов** загружены, показаны в preview и подтверждены через UI; карточки показывают «6 из 6 загружено».
6. Подбор с предзаполненным потоком 420 000 ₽ → новая сумма/срок → версия 2 → сравнение → локальная демозаявка.
7. Связанный чат → ответ с тем же расчётом → совмещённый режим → история. Диалог сохраняется.
8. Изменение доли кабинета через доступный slider, загрузка демокредита, стресс-прогноз.
9. Локальное обращение к сотруднику из рабочего экрана.
10. Атомарное изменение предположений → отрицательный прогноз → уведомление без перезагрузки → возврат к базовым значениям.
11. Desktop 1440 px и mobile 390×844: визуально просмотрены лендинг, кабинет и профиль. На мобильных лендинге и кабинете `scrollWidth === viewportWidth === 390`.
12. Чистая итоговая браузерная сессия: **0 errors, 0 warnings** в консоли.

Браузер нашёл и позволил исправить сбой очистки эффекта прокрутки при уходе из чата; дополнительно добавлен ErrorBoundary. Исправлены мобильная кнопка меню, горизонтальный overflow лендинга и восстановление preview неподтверждённого документа. Черновик незавершённого подбора сохраняется при переходах между экранами в текущей сессии; после полного reload незавершённую анкету подбора нужно начать заново. Сохранённые подборы, документы и чаты остаются в базе.

## Ограничения и внешние зависимости

- Нет предоставленных ключей OpenAI и DaData. Live-ответ LLM и реальный реестровый запрос не проверялись. Подготовленные интеграции включаются через `.env`; без ключей доступны демопровайдер и тестовый справочник. Никаких обещаний боевого ИИ без ключа.
- Командный Go `/score` доступен через защищённый адаптер `/api/team-score`, но общий стек Go/Python в этом прогоне не поднимался. Локальный финансовый расчёт не выдаётся за ядро Лизы.
- SQLite — намеренный локальный выбор вместо PostgreSQL; подробности и границы в DECISIONS.md. Нет промышленного резервирования, банковской идентификации и гарантии безопасности размещения реальных клиентских данных.
- Сканированный PDF/OCR и произвольные банковские формы не поддерживаются. Схемы fixture документированы. Выписка требует явной категории операции `kind`.
- Docker отсутствует (`docker: command not found`). Dockerfile/compose подготовлены (standalone memory limit 256m), но контейнерная сборка и запуск не проверены. Локальный Node-запуск проверен.
- Figma-ссылка и отдельный автономный файл с названием из сообщения не были приложены. Использованы реальный `CODEX_MASTER_PROMPT.md`, весь приложенный MVP DOCX с таблицами и семь PNG; Figma не редактировалась.
- Нет реального одобрения, выдачи, платежей, передачи заявки в банк, платных ресурсов, SMS/email/push, OCR и автоматического банковского мониторинга. Записи заявок и обращений только локальные и явно маркированы.
