# Принятые решения

- Ветка `Толя` создана от origin/main 949a3ba. main и чужие файлы не редактируются. Все исходники нового продукта здесь.
- Актуальный Go API является stateless proxy `/score`. Он не хранит пользователя, сессии, документы, чаты. Изолированный Node BFF обслуживает новые вертикали; защищённый адаптер `/api/team-score` вызывает существующий Go-шлюз. Переписывать командное ядро не требуется.
- React + Vite + TypeScript, Express и встроенная SQLite Node 24: запуск на Mac без дополнительной БД, бесплатных/платных облачных ресурсов. Это намеренное отклонение от рекомендуемой PostgreSQL при пустом репозитории: репозиторий уже существует, scope строго папка Толи. Миграция/seed воспроизводимы; промышленная БД и многопроцессная эксплуатация вне демо.
- Новое ТЗ расширяет прежнее ограничение CSV. Поддерживаются подготовленные шаблоны CSV/XLSX/DOCX/PDF с извлекаемым текстом. OCR не заявляется. Первичное распознавание не считается подтверждением достоверности.
- Сохранённый официальный registryRecord отделён от уточнений пользователя. Регистрация по телефону без SMS явно обозначена как упрощённая.
- Новое ТЗ не предусматривает рейтинг/вероятность выдачи. Используются прозрачные платежи, DSCR и ограничения; финальное решение за банком. Каталог исключительно синтетический, не актуальные предложения банка.
- Прямой Figma-доступ не подтверждён, ссылки нет. Визуальный источник — семь предоставленных PNG. Звёзды-заглушки заменяются SVG-инфографикой и графиками; чужие бренд-иллюстрации не копируются.
- LLM через gpt-5.4-mini по указанному ТЗ; модель настраивается AI_MODEL. Проверены официальные Responses и function calling docs 16.10.2026. API-ключ не предоставлен, платные вызовы не выполняются. Без ключа показываем «ИИ не подключён» и отдельно маркированный демо-ответ.
- В шаблоне выписки kind обязателен: не принимаем заёмные поступления за операционный поток. Аннуитетный график и fixture платежей согласованы программно. В календарном усреднении учитываются месяцы без операций между первым и последним месяцем.
- npm audit первоначально сообщил о 5 moderate проблемах UUID и sprintf через CLI Mammoth. Применены scoped overrides: ExcelJS → UUID 11.1.1 (совместимый CJS v4), Mammoth → argparse 2.0.1 (CLI не используется). Runtime-парсеры повторно покрыты тестами; audit после обновления — 0 уязвимостей.
- Справка API: https://developers.openai.com/api/docs/guides/function-calling и https://developers.openai.com/api/docs/models/gpt-5.4-mini . На дату проверки: $0.75 за 1M входных / $4.50 за 1M выходных токенов; квоты зависят от аккаунта. Локально ограничиваем 20 вызовов/день, 2 итерации инструментов, 1800 выходных токенов; ключи только на сервере.
- Продолжение 17.10: незавершённый подбор переживает reload через ограниченный sessionStorage, ключом служит идентификатор текущего авторизованного workspace из `/api/config`. Не используем имя/ИНН как идентичность: два бизнеса с одинаковым именем не разделяют черновик. Схема версионируется и проверяется при чтении/записи; срок 24 часа, очистка при logout, fallback на память при запрете/квоте. Хранятся только поля анкеты и ссылки на собственные подборы, не документы/переписка/учётные данные. Это удобство локального демо, не механизм серверной авторизации.
- Новый UX 17.10: `/demo` — публичная read-only фабрика fixture и отдельный ограниченный пересчёт без сессий/записи в SQLite. Тур получает тот же read-only пример только как отдельную view-model Cabinet; основной state/контекст AI не заменяется. В интерфейсе обычного аккаунта удалены демовход, добавление случайного кредита и автоматическая загрузка fixture. Старые API и ранее сохранённые записи оставлены для совместимости, UI их не вызывает.
- Регистрация: три сгруппированных экрана анкеты + отдельный шаг аккаунта. Ветки держат независимые ответы при переключении; скрытые поля незарегистрированного проекта нормализуются перед сохранением. Правило пароля согласовано на **8–128 символов** с сервером; маска поддерживает +7/7/8/10 цифр и редактирование в середине. Хеширование scrypt не менялось.
- Layout: app-shell занимает 100dvh; внутренние скроллы у кабинета и переписки, закреплённый composer. Split ограничен не только процентами, но и минимумами 420/370 px; при ширине менее 1100 px — одна область с вкладками. История на телефоне — явная модальная выдвижная панель, не новый маршрут. Финансовое ядро и формулы не изменены; проценты в инфографике — отношение сумм, не вероятность.
