# Проверка полей кредита · 18 октября 2026

По скриншоту с английской ошибкой сервера добавлена проверка формы до отправки:

- Обязательные поля, положительная первоначальная сумма, неотрицательный остаток и технический максимум суммы 1 трлн ₽.
- Ставка 0–100%, сроки — целое число 1–120 месяцев. Остаток не больше первоначальной суммы, общий срок не меньше оставшегося.
- Действительные календарные даты: выдача с 01.01.1900 по сегодня; следующий платёж от сегодня до 10 лет вперёд (технический горизонт MVP). Это ограничения интерфейса/данных, не банковские лимиты или решение о кредите.
- Название — 1–100 печатных символов с буквами/цифрами, без управляющих и скрытых знаков. Смысл произвольного пользовательского названия автоматически не оценивается.

Форма не использует системные validation-подсказки браузера. Неверное непустое значение подсвечивается сразу, пустое — после посещения поля или попытки сохранения. Рамка/подпись красные, конкретная русская ошибка находится под полем и связана через `aria-describedby`/`aria-errormessage`. При сохранении фокус переносится к первой ошибке. Исправление убирает подсветку. Невалидная форма не вызывает API и не меняет финансовое состояние; значения не исправляются и не обрезаются молча.

Сервер сохраняет обязательную проверку и использует те же межполевые ограничения. Ответы содержат `fields` для привязки ошибок к полям. Общий обработчик больше не публикует английские сообщения Zod и внутренние пути вроде `rate:`; технические/сетевые сбои имеют русское безопасное описание. Ошибки формы кредита не дублируются глобальным toast: поле или локальное сообщение объясняют проблему.

## Проверка

`npm run verify` — форматирование, TypeScript, production build и 85/85 тестов. Новые тесты воспроизводят ставку 232%, огромный срок, год 33333 со скриншота; границы, пустые поля, даты, связанные суммы/сроки, имя, локализацию ошибок и прямой обход UI через API. Неверные запросы возвращают 422 без записи договора; корректные сохраняются.

`scripts/check-facility-validation.cjs` — браузер: пустая форма, фокус, красная подсветка, сообщения на русском, ноль запросов с неверными полями, исправление в реальном времени, серверная ошибка конкретного поля без дублирующего уведомления, успешное сохранение, 1440 и 390 px. Дополнительно проверены сквозной кабинет и форматирование денежных полей. Тестовый ответ 422 намеренно присутствует в сетевом журнале, ошибок JavaScript нет.

Проверки выполнены на отдельном 4174 с SQLite в `/private/tmp/alfa-validation.*` и `/private/tmp/alfa-validation-final.*`; пользовательская база не использовалась для тестовых записей, платных запросов и банковских действий не было. Перед перезапуском основного сервера создана SQLite-копия `/private/tmp/alfa-before-validation-mdPfyW/alfa.sqlite`. База и ключи в Git не добавлялись. Основной сайт остаётся на 4173; тестовый сервер и браузер закрываются после проверки.
