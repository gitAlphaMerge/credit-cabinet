# Повторные анкеты с одного устройства — 25.10.2026

Исправлена блокировка «У вас уже есть отправленная заявка». Ограничения на общее количество прохождений с одного устройства нет; удалять cookies не требуется. Кнопка «Начать сначала» по-прежнему доступна в шапке. Прямой переход на `/onboarding` после отправленной заявки также начинает отдельный пустой проход. Перезагрузка незавершённого онбординга сохраняет его ответы и явный текущий шаг.

Каждый новый проход после отправки получает отдельного анонимного владельца и новую серверную сессию через существующий механизм перезапуска. Старые досье, документы и кредиты сохраняются в базе у прежнего владельца. Это не история заявок в интерфейсе: новая сессия не получает доступ к старым данным. Количественного лимита прохождений нет; защита от слишком частых запросов остаётся.

Если ранее открытая анкета завершилась уже после подачи заявки, backend создаёт отдельное досье с только что введёнными ответами. Cookie меняется после успешного сохранения новой заявки. Frontend обновляет идентификатор владельца и перезагружает корневое состояние при его смене. Повтор завершения текущего черновика остаётся идемпотентным. Редактировать уже отправленное досье этим запросом нельзя.

Старые вкладки не могут перезаписать новый проход: проверка `X-Journey-Workspace` сохраняется. Старый асинхронный расчёт завершает только своё досье. Дизайн, иконки, анимации, банковские решения и численное ядро не изменены.
