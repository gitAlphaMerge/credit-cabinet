# UX/UI, редакция 3 — аудит до изменений

25.10.2026, существующая ветка tolya/structure-v2. Контракт данных — shared/mvp2.ts, server/mvp2.ts и server/mvp2-routes.ts. Численные правила, каталог и порог 3 млн ₽ не меняются.

## Первопричина компоновки

Старая схема помещает в левую прокручиваемую карточку навигацию, повтор заголовка, форму и действия. Снаружи остаётся ещё заголовок страницы и footer. Внутри двух колонок снова используется попарная сетка, включая подтверждения компании; footer уезжает вместе с полями. Высокий чат имеет повторяющийся hint и пустое центральное сообщение. На мобильном обе панели идут последовательно вместо переключения. CSS .mvp-workspace исправляет размеры, но не разделяет ответственность за header, scroll region и действия.

Эталон: отдельный ApplicationWorkspace с единственным заголовком раздела, навигацией, одной областью скролла формы, отдельной фиксированной панелью действий и независимым чатом. На desktop без внешнего max-width, на mobile панели переключаются без размонтирования.

## Матрица полей frontend/backend

Все поля анкеты идут в PUT /api/mvp2/applications/:id, в объект questionnaire; при неполном вводе — приватный /api/journey/draft. Ниже обязательность означает действующий контракт, не дополнительное UI-ограничение. Ошибки — questionnaireErrors / missingFor, неверный формат не равен отказу.

| Поле / API-ключ | Тип и формат | Условие / обязательность | Ошибка или состояние |
| --- | --- | --- | --- |
| Отрасль, возраст / onboarding.industry,age | enum текущих справочников | знакомство | Выберите вариант |
| Цель, использование, возврат / purpose,usage,repayment | enum, подписи могут быть человечнее, wire-значения те же | знакомство → сводка запроса; редактирование явно | Выберите значение из списка |
| Сумма / amount | целые ₽, знакомство 300000–7000000; далее диапазон продукта | неизвестная допустима до подачи, draft=0 | Уточните сумму / диапазон продукта |
| Срок / term | целые месяцы, знакомство 1–60; далее minTerm/maxTerm | до подачи | Допустимый срок продукта |
| ИНН / inn | 10/12 цифр, контрольные разряды; fixtures сохранены | компания; публичный registry-запрос | Пусто / формат / поиск / не найдена / ошибка сервиса |
| Компания / companyConfirmed | boolean | после найденной компании | Подтвердите компанию |
| Полномочия / authorized | boolean | после найденной компании | Подтвердите полномочия |

| Кредиты / loans | yes/no/unknown | обязательства | Уточнить наличие; неизвестное не выдумывается |
| Долг и платёж / debt,monthlyDebt | nullable ₽ 0–1e12 | loans=yes | Укажите остаток / месячный платёж |
| Разовое погашение / balloonExpected,balloon,balloonPeriod | tri; положительные ₽; ISO дата не ранее сегодня | loans=yes и balloonExpected=yes | Конкретная сумма / действительная дата |
| Лизинг / leasing,monthlyLeasing | yes/no/unknown; nullable ₽ в месяц | платёж только leasing=yes | Уточнить лизинг / платёж |
| Сверка долга / debtReconciled | boolean | только найденное расхождение CSV и обязательств | Подтвердить итоговую нагрузку без двойного счёта |
| Сезонность / seasonality | tri | особенности, unknown допустим | Нет новой обязательности |

## Расхождения → реализация / проверка

| Требование | До изменений | Целевая проверка |
| --- | --- | --- |
| 60/40, полноразмерные панели | формально есть, но вложенные заголовки/скролл и подвижный footer | Компания 1440×900/1920×1080, геометрия и screenshot до тиражирования |
| Mobile Анкета/Помощник | панели друг под другом | 360/390/768, сохранность полей и чата при переключении |
| Быстрые действия чата | только setDraft, требуется повторная отправка | одно нажатие → сохранённый вопрос и ответ/честный offline |
| Справочная помощь без LLM | отсутствует | единый каталог, серверный reference-ответ с источником; свободные вопросы прежнему провайдеру |
| Общая карта пути | только локальные 3 шага | локальный шаг не обозначает завершение кредита |
| Финансирование | повтор всех ответов знакомства | «Ваш запрос» с явным редактированием |
| CSV | нет образца/удаления/показателей в карточке | несколько счетов, плохой CSV, недостаток истории, consent return, реальные извлечённые цифры с периодом |
| Валидация | длинный дублирующий список ошибок | короткая сводка-ссылки, фокус видимого поля |
| Обработка | процент по количеству стадий не означает время | без выдуманного %, реальные статусы + обновить |
| Конвейер/договор/выдача | уже рабочие | сохранить и повторно пройти до ACTIVE/кабинета, все 4 исхода |

Согласия не переписываются юридически. Единый существующий набор содержит флаг bki; UI может отдельно показать его смысл, не менять принятую формулировку/фиксацию без изменения контракта. Регулируемый разделитель необязателен и не заменяет фиксированный эталон.
