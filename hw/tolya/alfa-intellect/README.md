# Альфа-Интеллект · автономный MVP Толи

Все исходники изолированы в `hw/tolya/alfa-intellect`, ветка `Толя`. Локальный продукт: публичный лендинг → две ветки анкеты → аккаунт → кабинет / чат / подбор / профиль. Реальных банковских действий нет.

## Запуск на Mac

Требуется Node.js **24+** и npm. Из корня репозитория:

```sh
cd hw/tolya/alfa-intellect
npm ci
npm run fixtures
npm run build
npm start
```

Откройте http://localhost:4173 . Для разработки с Vite и горячим обновлением: `npm run dev` (работает и при наличии `dist`). Для production-просмотра после изменения UI выполните `npm run build`, затем `npm start`. Ctrl+C останавливает сервер. Порт меняется `PORT=4174 npm start`.

Если порт занят прежним процессом, запуск завершится с кодом 1 и понятным сообщением. Сначала остановите прежний сервер либо выберите другой порт: два запуска не обновляют серверный код друг друга.

Без ключей всё приложение запускается. SQLite (`var/alfa.sqlite`) создаётся миграцией v1 автоматически, файлы хранятся в той же базе и изолированы по пользователю. `var/` в git не попадает. Для проверки: `npm run verify`. Для smoke-тестов используются отдельные временные БД, основная не очищается.

## Демо и сценарии

Публичное **http://localhost:4173/demo** открывается без регистрации и не создаёт пользователя, сессию, кредит или записи в вашей истории. Переключаются ООО, ИП и проект, кабинет, расчёт, пример переписки и документы; сумму/срок можно пересчитать на синтетических данных. Демо отсутствует в авторизации и обычном кабинете. Для своей работы пройдите трёхэкранную анкету и отдельную регистрацию: телефон в маске `+7 (999) 123-45-67`, пароль от **8 символов**, собственные русские ошибки и переключатель видимости. SMS отсутствует; это не банковская идентификация.

1. Пройдите анкету или откройте демо → профиль через имя компании.
2. Тестовые ИНН: `7712345678` (ООО), `770123456789` (ИП). Подтвердите результат.
3. У любой из шести карточек нажмите «Загрузить», выберите файл, проверьте извлечённые поля и подтвердите. Для локальной проверки можно скачать шаблон с явно синтетическим примером и самостоятельно загрузить его через профиль или скрепку чата: хранилище одно. Автоматической подстановки примеров в профиль больше нет. Сканированный PDF без текстового слоя не поддерживается. Только подготовленные формы, до 8 МБ.
4. Подбор → цель → сумма/срок → свободный поток. Откройте расчёт, измените параметры для версии 2, сравните. Обсудите подбор в связанном чате.
5. «Перейти к оформлению» → выгрузите JSON-досье, подтвердите тестовый контакт → сохраните локальную демозаявку. Ничего не отправляется в банк.
6. В обычном кабинете без кредита всегда есть сводка с 0 ₽, ближайший платёж, пустой график и честный прогноз «Недостаточно данных». Кнопки добавления демокредита нет. Кредит с графиком и стресс-сценарием смотрите в публичном `/demo`. Ранее сохранённые тестовые договоры не удалены и маркируются локально.
7. Первое обучение: пять небольших подсказок рядом с компонентами, временный учебный кредит только в UI. «Завершить»/«Пропустить» убирают все примерные цифры, сохраняется только флаг обучения. Повторный запуск — `?` в шапке.
8. В split view чат можно скрыть и восстановить, открыть отдельной страницей; ширина меняется мышью и клавиатурой. На узком экране — вкладки. В полном чате история независима, на телефоне это закрываемая панель с фокусом и затемнением. Quick Actions сразу отправляются и защищены от двойного клика.

Отчёт нового UX-этапа, соответствие пунктам 1–14 и перечень локальных скриншотов: `docs/UI_REDESIGN.md`. `npm run verify` проверяет форматирование, TypeScript, production build и 30 тестов.

Незавершённый подбор автоматически сохраняется в `sessionStorage` текущей вкладки: шаг, сумма, срок, цель и денежные параметры восстанавливаются после обновления страницы. Черновик привязан к аккаунту, удаляется при выходе и истекает через 24 часа; закрытие вкладки также завершает его хранение. «Сбросить черновик» возвращает начальные параметры без удаления сохранённых расчётов. Документы, пароли и переписка в это хранилище не попадают. При запрете браузерного хранилища анкета продолжает работать в памяти, а интерфейс предупреждает об ограничении. Сохранённые расчёты и документы остаются в серверной SQLite независимо от черновика.

## Интеграции

При необходимости создайте локальный `.env` по `.env.example` (секреты не коммитить):

- `OPENAI_API_KEY`: серверный ключ OpenAI. `AI_MODEL=gpt-5.4-mini`. Responses API и ограниченные функции чтения контекста, расчёта и предложения изменения (без сохранения до подтверждения). `AI_DAILY_CALL_LIMIT=20`. До 1800 выходных токенов и трёх API-вызовов на сообщение. Платные вызовы в ходе разработки не выполнялись. См. docs/DECISIONS.md для ссылок и стоимости на дату проверки. Реальные квоты зависят от аккаунта.
- `DADATA_API_KEY`: серверный ключ DaData, `findById/party`. При отсутствии ключа или технической ошибке используется явно демонстрационный справочник. Пустой реальный результат не подменяется выдуманным.
- `TEAM_API_URL`: адрес существующего Go-шлюза команды; `/api/team-score` — защищённый адаптер текущего контракта. Подбор здесь использует отдельную демонстрационную модель платежей. Он не выдаётся за боевое ядро Лизы и не меняет его.
- `COOKIE_SECURE=true`: для эксплуатации за HTTPS. По умолчанию localhost и `HttpOnly`, `SameSite=Strict`, срок 7 дней. Пароли scrypt с индивидуальной солью; cookie содержит случайный токен, в базе хранится его SHA-256.

## Документы и данные

Поддерживаются CSV, XLSX, DOCX и текстовый PDF по шаблонам `fixtures/`. Сначала проверка размера/формата и извлечение → preview → явное подтверждение. Дубликат файла у одного пользователя не создаёт второй blob. Статус «Загружен» только после подтверждения. Выписка даёт денежный поток; ОФР — бухгалтерскую выручку/прибыль; модель — плановые показатели. Не взаимозаменяются. Валюта RUB. В CSV выписки обязательна колонка `kind`: `operating` (операционное движение), `financing` (заёмные средства), `debt` (обслуживание долга), `transfer` (внутренний перевод). Только операционные движения участвуют в свободном потоке; платежи по долгу учитываются отдельно. Автоматическая классификация произвольного назначения платежа не заявляется. Сохраняются исходные операции и строки графика, включая даты и части платежа.

## Ограничения

Локальный хакатон-прототип, не production-сервис. Нет SMS, OCR, реальных банковских счетов/выдач/платежей/заявок, актуального банковского каталога. Нет автоматического мониторинга. LLM и DaData требуют ключей и проверки владельцем аккаунта. Загрузка произвольных банковских форм не гарантируется; шесть подготовленных fixture покрыты тестами. База локальная SQLite, без промышленного резервирования и многопроцессной миграции. Макеты использованы как семь предоставленных PNG: Figma-ссылка отсутствовала. Иллюстрации и графики построены в HTML/CSS/SVG.
