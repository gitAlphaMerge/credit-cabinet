# Артём — бэк, API, инфра

Владеешь: Go API (`GET /health`, `POST /score`), `docker-compose.yml`, сборка zip на сдачу.
Контракт `/score` (черновик): вход — данные бизнеса (оборот, возраст, долги, отрасль), выход —
`score`, `top_factors` (3 шт.), `next_step` (текст). Модель — отдельный python-сервис, его делает Лиза.
Ограничения: `mem_limit` у каждого сервиса, в сумме до 600M. Деплой — пуш в main → Actions → сервер Саши.
Открыто: формат обмена Go ↔ python (HTTP или gRPC), где живёт `next_step` — решаем с Сашей.

## Как вести этот файл
Сюда — всё, что ты узнал по своей сфере и что пригодится команде или твоему агенту: решения,
ссылки, цифры с источником, тупики («пробовал X — не работает, потому что…»). Пишешь коротко,
новое сверху. Агент читает этот файл перед задачей по твоей сфере.
