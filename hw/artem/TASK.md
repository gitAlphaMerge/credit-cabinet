- [ ] ml-model не торчит наружу (убрать `ports: 5000:5000`, добавить `depends_on`), порт api из `${PORT:-8080}`

**Зачем.** Сейчас api отдаёт свой хардкод `score: 0` и в модель не заходит. На демо нужен один настоящий путь: ввёл данные → ответ из модели.
**Контракт.** Образец — раздел 2.8 общего ресёрча: `decision_id`, `model_version`, `status` (закрытый список, без «одобрено»), `instrument`,
`limit_rub.now / after_actions`, `valid_until`, `reasons`, `actions`, `alternatives`, `human_review_available`. Пока модель может отдавать этот JSON с фиксированными числами — главное, что провод и формат настоящие.
**Готово, когда:** `curl -X POST localhost:8080/score -d '{...}'` отвечает из питона, а при `docker compose stop ml-model` — 502, а не висит.
