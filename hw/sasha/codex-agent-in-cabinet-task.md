# ТЗ Codex: посадить нашего агента в чат кабинета Толи

Ветка `codex/agent-in-cabinet` (уже создана: `origin/Толя` + `codex/agent-dialog`). Рабочая папка — этот клон. Коммитить сюда, никуда не пушить.

## Зачем

В кабинете Толи (`hw/tolya/alfa-intellect`) чат отвечает через `AIProvider` (`server/ai-provider.ts`):
`OpenAIProvider` при `OPENAI_API_KEY`, иначе `DemoProvider` (выбор в `server/app.ts` около стр. 454).
Наш агент (`services/agent`: приёмщик → роутер → ядро Лизы → объяснялка → страж) прошёл eval, но живёт только в sim и телеге.
Нужен третий провайдер: `TeamAgentProvider`, который ходит в наш агент по HTTP. Один разъём, без переписывания ни той, ни другой стороны.

## Что сделать

1. **Python: HTTP-обёртка агента** — `services/agent/server.py`, только stdlib (`http.server`, `json`), без новых пакетов.
   - `POST /turn` `{session_id, text, card}` → `{text, mode, status, view}`; `GET /health` → `{"ok": true}`.
   - `card` — карточка клиента из кабинета (см. п. 3). Из неё заполняется стартовый `state`: цель, сумма, срок из подбора попадают в `state["need"]` сразу, чтобы агент **не переспрашивал известное**.
   - Сессии в памяти процесса, ключ `session_id` (id чата Толи). Порт из env `AGENT_PORT`, по умолчанию 8090.
   - Ходит в ядро тем же путём, что `dialog.py` сейчас (локальное ядро или окошко — как уже устроено), `services/ml-model` не трогать.
2. **TS: `TeamAgentProvider`** в `server/ai-provider.ts`, реализует `AIProvider`.
   - Включается при `TEAM_AGENT_URL`; приоритет: `TEAM_AGENT_URL` → `OPENAI_API_KEY` → демо. Правка `app.ts` минимальная, только выбор провайдера.
   - Таймаут 20 с; при ошибке сети — честный текст «Ассистент сейчас недоступен, попробуйте через минуту», `mode: "agent-offline"`, без падения запроса.
   - `mode: "team-agent"` в ответе, чтобы в UI было видно, кто ответил.
3. **Карточка клиента** (`card`): собрать из `contextOf(state, selectionId)` только то, что агенту можно видеть:
   цель, сумма, срок, инструмент подбора, подтверждённые документы (категория, период, без сырого текста), обязательства.
   **Нельзя в карточку:** ИНН, ФИО, телефон, email, название компании, номера счетов. Тест на это обязателен.
