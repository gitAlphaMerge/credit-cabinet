# Где брать данные · 10.10

Главное: размеченных выписок МСБ («вернул / не вернул») в открытом доступе нет, это банковская тайна.
Поэтому скоркарта экспертная (решение 7.10), а выписки синтетические. Открытые данные нужны, чтобы синтетика была похожа на жизнь,
и чтобы показать жюри, какие данные помощник подтянет в проде.

Метка проверки: «200»: сайт открылся 10.10 с нашего компа; «не открылся»: таймаут или защита от ботов, сайт существует, но руками не проверен.

## 2. В проде: что помощник подтягивает о клиенте (это слайд для жюри)

**Клиент даёт сам:**
- выписка своего банка (CSV, PDF) или выгрузка из 1С (формат обмена 1С с банком, текстовый файл)
- выписки из других банков: Open API между банками отложен дальше 2026 (ресёрч 6.10, источник S63), так что пока только загрузкой
- отчётность, контракты, сметы: на последней ступеньке, не сразу

**Банк проверяет по ИНН, без участия клиента:**
- ЕГРЮЛ / ЕГРИП (egrul.nalog.ru): возраст бизнеса, ОКВЭД, руководитель · не открылся
- реестр МСП (rmsp.nalog.gov.ru): статус малого бизнеса, нужен для льготных программ и зонтика · не открылся
- картотека арбитражных дел (kad.arbitr.ru): суды с поставщиками и налоговой · 200
- ФССП, банк исполнительных производств: долги по исполнительным листам · 200
- Федресурс (fedresurs.ru): банкротства, залоги · защита от ботов, сайт есть

**Только с согласия клиента:**
- кредитная история из БКИ (НБКИ, ОКБ, Эквифакс): старые кредиты и просрочки
- данные ФНС о доходах через согласие клиента

## 3. Чего не делаем

Не скрейпим ничего в прототипе: для демо хватает синтетики плюс одного «живого» примера, где помощник показывает, что взял из ЕГРЮЛ.
Публичные датасеты дефолтов (Polish, GMSC) в продукт не идут (решение 7.10): это не МСБ и не выписки.
