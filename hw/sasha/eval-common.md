# Общая часть задания eval (одинаковая для веток A и B)

## Зачем
Выбрать LLM (или связку) для агента кредитного кабинета `services/agent` и доказать выбор
воспроизводимым eval на НАШИХ диалогах, а не публичными лидербордами. Eval должен ловить
реальные провалы агента, в первую очередь петлю «На что нужны деньги?» (цель ловится только
ключевыми словами в `intake_rules.py`: «хочу купить кофемашину», «ремонт помещения», «аренда
склада», «на товар для маркетплейса» дают None, вопрос повторяется).

## Что должен уметь итоговый eval (критерии приёмки)
1. Одна команда прогоняет матрицу «кандидат-модель × набор» и пишет таблицу
   `services/agent/eval/reports/<дата>-models.md` (+ JSON рядом): по каждому кандидату
   точность слотов (argument extraction), доля диалогов с петлёй (повтор одного вопроса ≥2 раз),
   ошибки чисел относительно ядра (hallucination), нарушения стража, pass^3 по персонам,
   p50/p95 латентности на реплику, токены/стоимость демо, размер модели и лицензия.
2. Детерминированный слой (код) идёт первым, LLM-судья только для тона и только другой семьи.
3. Шаблонный режим без LLM входит в матрицу как baseline: кандидат засчитывается, только если обыгрывает его.
4. Отдельный набор `eval/data/loop-*.json` на свободные формулировки цели (≥30 реплик,
   русский разговорный, опечатки, голосовой ввод) с эталонными слотами. На текущем коде он
   ОБЯЗАН показать петлю (красный), это доказательство, что eval ловит баг.
5. Hidden-набор: каталог `eval/data/hidden/` с README, как его наполняет человек не из разработки;
   сам набор не генерировать и в промпты не класть. Контаминация: фразы eval не попадают в системные промпты.
6. Кандидаты: 4-6 моделей с открытыми весами ≤120B, доступных через OpenRouter (ключ в `.env`
   корня, `OPENROUTER_API_KEY`), плюс текущая `qwen3:8b`. Каждую подтвердить карточкой на
   huggingface.co (лицензия, параметры, дата) веб-поиском; SEO-подборки «топ LLM» не источник.
   Нет источника = «не нашёл». Выбор кандидатов обосновать первичными лидербордами
   (BFCL для function calling, IFEval, русскоязычный MERA или аналог) со ссылкой и датой.
7. Локальный CPU-замер: если Ollama отвечает на `http://localhost:11434` за 10 с, замерить
   латентность и RAM двух самых маленьких кандидатов; не отвечает, в отчёте «не замерено», не выдумывать.
8. `services/agent/eval/README-models.md`: как запустить, как добавить модель, как читать таблицу,
   какие выводы факт, какие мнение, что неизвестно.
