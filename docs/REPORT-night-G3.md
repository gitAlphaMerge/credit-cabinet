## Не сделано и почему

Продуктовые пункты реализованы. Полная зелёная приёмка общих наборов не получена: обычный набор ограничен ENOMEM/загрузчиком, полный QA выявил нестабильное серверное сравнение версии. Чужие серверные файлы и инфраструктура тестов не исправлялись.

## Нужно от других

Для G3 изменений чужих исходников не требуется. `hw/tolya/alfa-intellect/tests/qa/q1-sequences.test.ts:161`: владельцу серверной цепочки нужно разобрать нестабильное сравнение версии 3/2 в HTTP-последовательностях; изолированный seed зелёный, полный прогон красный. Приёмщику также нужен обычный `npm test` вне ограничения ENOMEM.

## Не проверено

Причина нестабильности Q1 HTTP-теста. Реальный браузер, визуальное совпадение с оригиналом по видео, FPS/CPU на слабом ПК, фактический CLS и фактический горизонтальный скролл на устройстве. Есть статические проверки сетки и проверки таймеров/RAF с управляемыми часами, они не заменяют браузерные измерения.
