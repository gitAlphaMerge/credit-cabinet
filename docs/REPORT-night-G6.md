1. Открой главную, начни анкету, затем кабинет без кредита: увидишь прежнюю главную, одну анкету рядом с заголовком и пустую папку рядом с точным текстом о данных кредита. Проверь светлую и тёмную темы на 390/768/1280 px.
2. Открой профиль, сравни шесть документных карточек: увидишь выписку, баланс, отчёт, нейтральную модель, бизнес-план, график долга. Подписи и загрузка работают, на карточку один крупный рисунок. Проверь белую подложку и размеры без обрезки.
3. Открой пустую историю подборов, создай подбор, сравни результат и альтернативы: увидишь папку при пустой истории, затем иллюстрацию по ID продукта или нейтральный лист. Передай заявку: отказ, дозапрос и оффер показывают свой фактический статус.
4. Открой «Моя заявка» без заявок, затем info_requested без документов: увидишь разные пустые состояния. Добавь и подтверди документ, увидишь его тип рядом с записью, доступность «Дослать» сохраняется. Проверь offered/signed/disbursed и отличие expired от withdrawn.
5. Войди менеджером, открой пустую очередь, красную заявку и досье: увидишь готовность без красных заявок, статусы строки/досье, предметы четырёх проверок с текстовым исходом, типы документов и их свежесть. БКИ показывается только при соответствующем стоп-факторе. Проверь длинные записи и масштаб 200%.
6. Отключи сервер для запроса очереди или заявки: увидишь рисунок ошибки и существующее сообщение с возможностью повтора. Восстанови соединение, повтори запрос, проверь, что загрузка и успех не подменяются рисунком ошибки.
