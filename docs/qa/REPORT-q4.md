Обещание кредита от LLM -> ложное банковское решение -> враждебные ответы через настоящий speak/guard/fallback (context/core.md, «не считает, не решает, не придумывает цифры»; services/agent/PERMISSIONS.md, «Говорить ... обещать сроки выдачи»).
ПДн в истории и trace -> чувствительные данные на диске -> синтетические маркеры в чате и поиск по сохранённой сессии (TASK.md, Q4.3: «Каждое попадание = находка с файлом»; .codex-ctx/case.txt, стр. 9: «безопасность, надежность»).
Принятая альтернатива теряет условия -> клиент получает другой продукт -> сверка повторного score и оффера с выбранной карточкой (docs/v2-contract.md:40, «полный повторный проход»; .codex-ctx/inputs-2026-10-22.md, раздел 5, «изменение условий ... или другой продукт»).
Редактируемый возраст вместо реестра -> возможный скоринг неподтверждённых сведений -> захват анкеты core при enrichment из комплаенса (.codex-ctx/inputs-2026-10-22.md, раздел 4, «Из комплаенса можно получить часть данных для скоринга»; приоритет источников явно не задан).
Неподтверждённая старая выписка блокирует свежую -> потеря заявки -> сравнение чистого сценария с добавлением черновика (docs/v2-contract.md:20; context/core.md, «DSCR считается только на подтверждённом»).
