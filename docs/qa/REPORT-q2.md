### Fault injection и восстановление

| Сбой | Клиент | Журнал/досье | Сохранность и повтор |
|---|---|---|---|
| fetch offline | 503, короткий JSON без стека | `scoring pipeline failed`, сырой текст ошибки | draft, версия/события/досье без изменений; тот же Idempotency-Key после восстановления -> offered; replay без новых записей |
| upstream 500 с валидным телом | 503 | та же категория, `Core unavailable` | то же |
| невалидный JSON | 503 | та же категория, текст JSON parser error, потенциально содержит фрагмент тела | то же |
| `{}`, limit строкой, limit < 0 | 503 на submit | validateReply кидает ApplicationError; ветка не пишет console.error | то же |
| upstream отвечает после дедлайна | 503 за примерно 30,04-30,08 с | `scoring pipeline failed`, TimeoutError | AbortSignal реально прерывает ожидание, таймер фейка очищается; повтор работает |
| dependency комплаенса кидает 500/timeout | 503 | `scoring pipeline failed` | ядро не вызывается; исходный draft сохранён; повтор -> offered |
| локальный источник недоступен | 200 + info_requested | причина COMPLIANCE_SOURCE_UNAVAILABLE в отчёте комплаенса; досье N < M | событие и досье сохранены; client_update после восстановления -> offered |
| BKI кидает timeout | 200 + info_requested | досье с hole bki, unavailable | client_update после восстановления -> offered |
| адаптер findCompany: injected 500/TimeoutError | RegistryError с кодом 5xx и безопасным текстом | console-журнал адаптера отсутствует | чистый адаптер, состояние не изменяет |
| LLM выключена | чат mode=demo, submit -> offered | обычное досье | полноценный путь не требует LLM |

У комплаенса по контракту принудительные локальные моки: сетевые 500/таймауты не возникают сами. Поэтому отдельно тестируются throw на границе ComplianceGate, реальный unavailable-результат локального gate и транспортный адаптер реестра с инъекцией функции fetch. У последнего таймаут имитируется исключением TimeoutError, а не ожиданием 8 секунд; наличие AbortSignal проверяется. Реальный дедлайн 30 секунд измерен у ядра. DOM-спиннер не проверен, проверена ограниченность HTTP-ожидания.

# Числа

Нагрузка: `node --import ./scripts/qa/q2-runtime.ts scripts/qa/q2-load.ts` -> exit 0.

Хвост: `attempted:750,completed:750,errors:[],elapsed_ms:94256,limitMiB:256,peakMiB:406.64453125,exceedsComposeLimit:true`.

3 круга, в каждом 200 последовательных и 50 одновременных путей. Регистрация настоящая, включая scrypt, сессии/cookie, поиск и подтверждение синтетического ИНН, PATCH анкеты, upload+confirm выписки, подбор, создание заявки и submit. Проверяются offered и ровно один make_offer на каждый путь. Ядро детерминированно подменено фейком в Dependencies, лимит 1 млн, стопов/пропусков нет; LLM отключена.

Клиенты имеют различные синтетические IP через X-Forwarded-For, loopback помечен доверенным proxy только в обвязке. Продакшен-лимиты не удалены. # Не проверено

Полный npm test из-за ENOMEM загрузчика tsx; браузерный DOM/XSS-рендеринг и реальный спиннер; Docker/cgroup и файловая SQLite под нагрузкой; реальные внешние сервисы и LLM; фактические N/M/лимит/стопы Python-ядра для CP1251/UTF8.
