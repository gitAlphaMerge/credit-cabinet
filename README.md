# credit-cabinet · git merge alpha

Альфа-Будущее хакатон, трек «Умный кредитный кабинет предпринимателя». Онлайн-этап 19–26.10.

## Где что

- `context/` — общий контекст: итоги созвонов, мок-кейс, решения. Читать перед любой задачей
- `hw/<имя>/` — домашка каждого: задача в `TASK.md`, результат кладёшь рядом
- `AGENTS.md` — инструкция для ваших ИИ-агентов (Codex читает сам, Claude Code через `@AGENTS.md`)
- `context/ALL.md` — весь контекст одним файлом: копируешь в начало чата с GPT/DeepSeek/Claude
- код (бэк, модель, фронт, `docker-compose.yml`) — заводит Артём

## Как сдавать домашку

Код — через ветку и PR в `main`. Не кодеры (доки, таблицы, слайды) — можно прямо в браузере:
открыть свою папку `hw/<имя>/` → Add file → Upload files → Commit. В `main` напрямую пушить
только свою папку `hw/`, остальное через PR.

## Как поднять за 2 минуты

### Сервисы и лимиты памяти
- api (Go API): порт 8080, mem_limit: 64m
- ml-model (Python-модель, заглушка): порт 5000, mem_limit: 384m
- frontend (Nginx): порт ${FRONTEND_PORT:-80}, mem_limit: 64m

Суммарно: 512M / 600M max.

### Запуск
```bash
docker compose up --build -d
```

### Проверка работы
- Healthcheck Go API: `curl http://localhost:8080/health`
- Скоринг Go API: `curl -X POST http://localhost:8080/score`
- Фронтенд: открыть в браузере `http://localhost` (или порт из FRONTEND_PORT)
- Контроль лимитов памяти: `docker stats --no-stream`

### Остановка
```bash
docker compose down
```
