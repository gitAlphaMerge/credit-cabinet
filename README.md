## Как устроено

```
Толя -> api -> ядро Лизы (POST /score)
Толя -> agent -> DeepSeek/шаблоны (POST /turn)
        agent -> api -> ядро Лизы (POST /score)

services/ml-model/app.py (окошко)
                        security.py   проверяет запрос
                        cores.py      выбирает ядро: сейчас временное, потом core.py Лизы
                        core_stub.py  временный расчёт на эталоне, только тестовые выписки
                        translate.py  переводит ответ ядра на язык сайта
                        journal.py    пишет каждое решение в журнал
```

Поля запроса и ответа: `context/api-contract.md`.

## Ядро: где писать и как проверять (Лиза)

Своё ядро пишешь в `services/ml-model/core.py`, функция `score(statement_csv, need, questionnaire) -> dict`.
Что она получает и что должна вернуть, написано в шапке `data/check_golden.py`.

```bash
python data/check_golden.py -k cash_gap     # один клиент
python data/check_golden.py                 # все 8
python data/check_golden.py --reference     # проверка самого экзамена, всегда 8/8
```

Когда `core.py` появится, окошко подхватит его само. Включить вместо временного: `CORE_ID=liza`.

## Как поднять

Без докера, одной командой (нужен только Python 3.11+):

```bash
python services/ml-model/app.py
curl http://localhost:5000/health
```

В докере:

```bash
docker compose up --build -d
docker compose down
```

| Сервис | Порт | Память |
|---|---|---|
| api (Go) | 8080 | 64m |
| ml-model (Python) | 5000, только с этой машины | 384m |
| frontend (nginx) | `${FRONTEND_PORT:-80}` | 64m |
| agent (Python, stdlib) | 8090, только внутри Compose | 96m |
| alfa-intellect (сайт Толи) | `${ALFA_PORT:-4173}` | 256m |

стенд: потолки mem_limit 864M, правило 600M пересматривает Артём

Контроль: `docker stats --no-stream`.
Ключ `DEEPSEEK_API_KEY` хранится в `.env` сервера и передаётся агенту через `env_file`.
Без ключа агент отвечает шаблонами. В контейнере `AGENT_CORE_URL=http://api:8080`;
без этой переменной локальный запуск и eval используют `core_local`.
Память агента хранится в volume `agent_state`: слоты, `need` и `view` переживают рестарт.
CSV выписки на диск не пишется, сохраняются только SHA-256 и признак получения.
Для нового расчёта после рестарта выписку нужно загрузить повторно.

## Как сдавать

Код через ветку `<имя>/<задача>` и PR в `main`. Доки, таблицы, слайды можно прямо в браузере в свою папку `hw/<имя>/`.
В `main` напрямую только своя папка `hw/`, остальное через PR.

Каждый день до 22:00 три строчки в чат: сделал / дальше / застрял.

## Запуск и проверка за 5 минут

Нужны Docker Compose и Python 3.11+ для smoke-проверки. Из корня репозитория:

```bash
docker compose up --build -d
python scripts/smoke.py --base http://localhost
```

Если задан `FRONTEND_PORT`, укажите этот порт в `--base`.
Compose ждёт готовности ml-model, затем API и frontend; сервисы перезапускаются автоматически.

По-настоящему считают `/anketa.html`, `/razgovor.html` и загрузка CSV или демо-выписки
на `/v2/chat.html`. В чате для расчёта используются демонстрационные значения потребности
и анкеты, результат приходит от ядра. Остальные страницы v2 и прочие сцены чата пока макет.
Smoke печатает таблицу OK/FAIL и возвращает код 1 при любой ошибке.
