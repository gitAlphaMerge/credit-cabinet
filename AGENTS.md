# AGENTS.md: контекст команды

Проект: Альфа-Хак, «Умный кредитный кабинет предпринимателя», команда из 5 человек.
Реальный кейс: [текст, слайды 7 и 9-11](../case-champion/research/case-2026-10-19/case.txt).
Сдача: 26.10.2026 в 18:00 на LMS. `context/mock-case.md` теперь только репетиционный архив.

Продукт: помощник ИП и ООО рядом с Альфа-Интеллектом. Ядро считает готовность,
инструмент и лимиты сейчас/после проверяемых шагов. Агент спрашивает и объясняет; решение за банком.
Ядро: `context/core.md`, `context/stop-rules.md`; API: `context/api-contract.md`.
Агент: `context/agent-architecture.md` (источник правды автора), общая рамка: `context/architecture.md`.
Витрина жюри: `README.md`, `docs/`, `THIRD_PARTY_NOTICES.md`; фактический контракт: `docs/openapi.yaml`.

Роли:
- Артём: API Go, провода, хранилище, безопасность, Docker.
- Лиза: ядро, ступеньки, скоркарта, пороги, коды причин.
- Саша: капитан, agent, контракты, золотые сценарии.
- Тоня: концепт, сценарий разговора, тексты, питч.
- Толя: alfa-intellect, концепт, инструменты, логика скоркарты, документы, финмодель.

Сервисы: `services/frontend/`, `services/api/`, `services/ml-model/`, `services/agent/`;
кабинет `alfa-intellect`: `hw/tolya/alfa-intellect/`. Провода и память: `docker-compose.yml`.

Правила:
- Сначала читай `context/`, потом делай. Документы описывают код, планы помечаются явно.
- Идеи и решения пишет человек, агент делает рутину. Не генерируй «3 идеи» за человека.
- У каждого сервиса есть `mem_limit`; стенд 864M, пересматривает Артём.
- Работай в ветке `<имя>/<задача>`, в main только через PR; своё клади в `hw/<имя>/`.
- Замечания: `hw/<имя>/REVIEW.md`; исправил пункт: `[x]` и ниже строка о сделанном.
- Конфиденциальные материалы, чужие презентации и данные финалов в репо не кладём.
- Правишь `services/frontend/`: сначала читай его `AGENTS.md`.
- Ядро: `services/ml-model/core.py`, функция `score`; готово = `python data/check_golden.py` зелёный.
