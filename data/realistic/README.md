# Грязные выписки · v2 · 13.10

Генератор реалистичных выписок МСБ и грязной упаковки поверх них. Писал Qwen по задаче `hw/sasha/dirty-data-task-qwen.md`, принимал Клод прогоном.

## Лизе

В `data/dirty/` 8 выписок `st_01 … st_08`: те же 8 сценариев, что в `data/golden.json`, но так, как их выгружает банк.
Разные разделители, Дебет/Кредит отдельно, cp1251 и BOM, шапка банка, обмен 1С, опечатки, дубли.
Ответы к ним открытые: `golden_dirty.json` (что должно выйти), `clean/` (те же операции чисто, с `label`), `answers/` (метка каждой строки грязного файла).

```
python data/realistic/check.py      # ядро на грязных файлах, сейчас 0 из 8: парсера нет
```

Готово, когда 8 из 8. Сначала парсер (кодировка, разделитель, шапка и подвал, Дебет/Кредит, дубли), потом пороги.
Есть ещё скрытый набор на 12 клиентов: его нет в репо, ядро прогоняет на нём Саша.

## Как собрано

```
python data/realistic/build.py      # собирает всё заново, детерминированно (2 сборки = одинаковые sha256)
python data/realistic/selftest.py   # инварианты: суммы, остатки, рабочие дни, эталон
python data/realistic/check.py --reference   # эталон reference.py против ожиданий
python data/realistic/realism.py    # отчёт реализма
```

`model.py` процессы и календарь, `calibrate.py` подгонка под нужный поток, `scenarios.py` сценарии, `dirt.py` грязь.
Скрытые сценарии подключаются из `data/hidden/hidden_specs.py` (вне git); нет файла, значит собираются только видимые.

## Правки Клода при приёмке

- `model.MONTH_RU`: `build.py` его звал, а список лежал только в `dirt.py`, сборка падала
- скрытые выписки, их ответы и описания вынесены в `data/hidden/`: в версии квена ответы всех 12 скрытых лежали в `data/dirty/golden_dirty.json`
- CSV через запятую: поля экранируются, раньше `-19,00` без кавычек разваливалось на два поля
- ИНН один на контрагента (раньше новый на каждой строке), перевод между своими счетами получает ИНН самого клиента

## Известные слабости (v3, не блокер)

- отчёт реализма помечает все файлы подозрительными по Бенфорду
- почти половина операций это комиссии банка; поставщики «ООО «Поставщик-0-…»», назначения шаблонные
- пятниц в 3,5 раза больше, чем понедельников
- налоги в «УФК по Тульской области», реквизиты ЕНП не сверены
- «1С» однострочный через `|`, настоящий формат: поле на строку
- CASH_GAP в 11 из 12 скрытых: как сигнал почти ничего не различает; OVERDUE_DEBT не покрыт (нет правила в `reference.py`)
- у `equipment_leasing`, `short_history`, `cash_out` добавилась причина CASH_GAP против `golden.json`, статусы и стопы те же
