## 1 · Главный путь: от лендинга до ответа

Три экрана. Анкета Тони даёт форму бизнеса и возраст, разговор добирает сумму, срок и источник возврата, выписка подтверждает. Ответ считает окошко на сервере, сайт сам ничего не считает.

```mermaid
flowchart TD
  L["Лендинг<br>/"]:::screen -->|Попробовать бесплатно| A["Анкета<br>5 вопросов"]:::screen
  A -->|Продолжить<br>все 5 ответов| R["Разговор<br>с агентом"]:::screen
  R --> Q1["Сколько нужно?"] --> Q2["На какой срок?"] --> Q3["Из чего вернёте?"]
  Q3 -->|по договору| Q4["Сумма договора"] --> S
  Q3 -->|выручка| S["Выписка CSV<br>свой файл или демо"]
  S --> API[("Go-шлюз → окошко<br>/api/score")]:::server
  API --> RES["Ответ:<br>статус, 3 цифры,<br>причины, график"]:::ok
  classDef screen fill:#fbe8e7,stroke:#ef3124,stroke-width:1.5px,color:#0b0b0c
  classDef ok fill:#e7f6ef,stroke:#13a463,stroke-width:1.5px,color:#0b0b0c
  classDef server fill:#d6e8fc,stroke:#0072ef,stroke-width:1.5px,color:#0b0b0c
      
```

## 2 · Что бывает после ответа

Четыре статуса без слова «одобрено». У «после шага» есть кнопка «Сделаю»: договор уходит как подтверждённый, цифры пересчитываются. Остальные документы в прототипе пока не принимаем.

```mermaid
flowchart TD
  RES["Ответ окошка"]:::server --> S1["Можно подавать"]:::ok
  RES --> S2["Можно после шага"]:::ok
  RES --> S3["Лучше другой инструмент<br>например лизинг"]:::ok
  RES --> S4["Нужен менеджер"]:::ok
  S2 -->|Сделаю: договор| RE["Пересчёт<br>договор = подтверждено"]:::server --> RES
  S2 -->|Сделаю: акт сверки| D1["«пока не принимаем»"]:::dead
  ANY["У любого статуса внизу"] --> M["Позвать менеджера<br>окно-заглушка"]:::dead
  ANY --> N["Начать заново → анкета"]:::screen
  classDef screen fill:#fbe8e7,stroke:#ef3124,stroke-width:1.5px,color:#0b0b0c
  classDef ok fill:#e7f6ef,stroke:#13a463,stroke-width:1.5px,color:#0b0b0c
  classDef server fill:#d6e8fc,stroke:#0072ef,stroke-width:1.5px,color:#0b0b0c
  classDef dead fill:#f3f4f5,stroke:#8a8a8e,stroke-dasharray:5 4,color:#6b6b70
      
```

## 3 · Когда что-то пошло не так

Ответы человека не теряются ни в одной ветке. Важно: ядро на сервере сейчас эталон, оно считает только демо-выписки. Свой CSV получит «не получилось прочитать», пока не включим ядро Лизы.

```mermaid
flowchart LR
  S["Выписка"] --> API[("окошко")]:::server
  API -->|422 кривая выписка<br>или незнакомая эталону| E1["Объясняем формат<br>+ загрузить другой"]:::ok --> S
  API -->|5xx или 30 с тишины| E2["Повторить<br>или менеджер"]:::ok
  E2 -->|Повторить| API
  A["Разговор без анкеты"] --> E3["Ссылка<br>на анкету"]:::ok
  classDef ok fill:#e7f6ef,stroke:#13a463,stroke-width:1.5px,color:#0b0b0c
  classDef server fill:#d6e8fc,stroke:#0072ef,stroke-width:1.5px,color:#0b0b0c
      
```
