# GitHub за 5 минут — шпаргалка к созвону

## Вариант «без гита», для всех, кто не кодит
1. github.com → войти → gitAlphaMerge/credit-cabinet
2. открыть свою папку `hw/<имя>/`
3. **Add file → Upload files** → перетащить файл → внизу **Commit changes**
4. всё: файл в репо, бот сам написал об этом в топик «коммиты»

Поставить галочку в задаче: открыть `hw/<имя>/TASK.md` → карандаш ✏️ справа сверху →
заменить `- [ ]` на `- [x]` у сделанного пункта → **Commit changes**. Доска в штабе обновится сама.

## Вариант «с гитом», для кода (Артём, Лиза, Толя с Codex)
1. ветка под задачу: `git checkout -b <имя>/<задача>`
2. работаешь, коммитишь
3. `git push -u origin <имя>/<задача>` → на GitHub кнопка **Compare & pull request**
4. заполняешь шаблон PR (что сделал, какой пункт закрывает, как проверить) → Create
5. Саша смотрит и вливает в main

## Слова
- **репо** — общая папка проекта в интернете
- **коммит** — сохранение с подписью «что поменял»
- **ветка** — своя копия, где можно ломать, не трогая main
- **PR (pull request)** — просьба «влей мою ветку в main», тут же обсуждение
- **main** — главная версия, то, что сдаём
