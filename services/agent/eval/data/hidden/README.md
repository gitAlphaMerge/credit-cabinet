# Независимый hidden-набор

Набор пока пуст: модель не генерирует hidden-примеры. Человек вне разработки пишет
живые реплики и персоны до просмотра ответов кандидатов. Минимум 30 реплик с expected
и 10 персон с независимым expected_status либо expected_escalation. Второй человек
проверяет неоднозначные метки. Формат реплик совпадает с loop-goals.json, персон
с personas-deepseek.json. Не использовать реальные ПДн и банковские выписки.

Хранить входы отдельно от обучающих данных, промптов и обычного репозитория. Передать
JSON в эту папку только оператору финального прогона. В runner включить --hidden,
который добавляет JSON из этой папки в отдельные задачи hidden_intake/hidden_dialog.
Не копировать примеры в системные промпты, не подбирать по ним словарь или пороги.
После раскрытия версии набора зафиксировать хеши; для следующего отбора собрать новый.
Пустой набор означает «не измерено», а не 100%. Результаты development-набора не
доказывают обобщение. Файлы JSON здесь исключены из git локальным .gitignore.
