# AGENTS.md — сайт (services/frontend)

Над сайтом работают двое людей с разными агентами (Саша: Claude Code, Толя: Codex) в одной папке.
Общие правила команды в корневом `AGENTS.md`, здесь только цикл сайта.

Источники дизайна, по старшинству:
1. `site.css`, блок `:root`: все цвета, шрифты, отступы. Новый токен идёт отдельным мелким PR, его вливают раньше страниц
2. `DESIGN.md`: какие экраны есть и откуда берётся дизайн
3. макеты Тони в `hw/tonya/mockups/`: как экран должен выглядеть

Цикл одной задачи:
1. Страница закреплена за одним человеком: перед началом напиши в телегу команды, какую берёшь. Правишь только её и свои новые файлы
2. Ветка `<имя>/site-<страница>` от свежего `main`
3. Проверка локально: `python -m http.server 8000` в `services/frontend`, открыть `localhost:8000/<страница>.html`, сверить с макетом на ширине 1280 и 375. `/api/*` локально не отвечает, живой ответ виден только на сервере
4. PR в `main` со скрином страницы. Вливает Саша
5. После мёржа сайт сам уезжает на https://158-160-212-36.sslip.io/ (`.github/workflows/deploy.yml`), готово = страница открылась там
